# 3.5 队列的表示与实现

交互式演示循环队列与带头结点链队列的初始化、入队、出队和取队头元素。页面将 `front`、`rear` 指针移动、结点链接和 C/C++ 伪代码逐行同步展示，适合课堂讲解与自学。

## 在线演示

https://ivychan72902.github.io/queue-representation-and-implementation/

## 功能

- 循环队列：演示队列回绕、队空条件、队满条件和牺牲一个存储单元
- 链队列：演示头结点、`Q.front->next` 队头和 `Q.rear` 队尾
- 初始化、`EnQueue`、`DeQueue`、`GetHead`
- 动画与代码高亮同步
- 桌面端和移动端响应式布局

## 本地运行

直接用浏览器打开 `index.html`，无需安装依赖或启动服务器。
